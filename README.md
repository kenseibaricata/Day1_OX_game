# Day1_○✕game

HTMLのみで実装した○✕ゲーム（Tic Tac Toe）です。

## 🎮 プロジェクトの概要

このプロジェクトは、HTMLの基本的な要素のみを使用して作られた○✕ゲームです。CSSやJavaScriptを使用せず、純粋なHTMLの機能だけでインタラクティブなゲーム体験を提供します。

## 🌟 特徴

- HTMLのみで実装（CSS・JavaScript不使用）
- セマンティックなHTML構造
- プルダウンで○✕を選択
- 3×3のゲームボード
- レスポンシブデザイン

## 🛠️ 使用技術

- HTML5
  - セマンティックタグ（header, main, footer, table など）
  - フォーム要素（select, option）
  - テーブルレイアウト

## 🎯 学習目的

1. HTMLの基本的な構造（セマンティックタグ）の理解
2. フォーム要素の使い方の習得
3. テーブルを使用したレイアウトの作成
4. JavaScriptなしでのインタラクティブ要素の実装

## 📝 ゲームのルール

1. 2人で交互にマスを埋めていきます
2. 各マスのプルダウンで○か✕を選びます
3. 縦・横・斜めのいずれかで3つ揃えると勝ち！
4. すべてのマスが埋まっても揃わない場合は引き分け

## 🚀 プロジェクトの起動方法

1. リポジトリをクローン
```bash
git clone [リポジトリのURL]
```

2. `tic-tac-toe.html`をブラウザで開く

## 📋 ファイル構成

- `tic-tac-toe.html` - メインのゲームファイル
- `README.md` - プロジェクトの説明

## 👥 プレイ方法

1. ブラウザで`tic-tac-toe.html`を開く
2. プレイヤー1とプレイヤー2が交互に手番を進める
3. 各マスのプルダウンから○か✕を選択
4. 3つ揃えば勝利！
